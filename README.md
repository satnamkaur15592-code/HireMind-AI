# HireMind-AI - Placement Predictor

A 3-stage placement prediction system, just like a real company hiring process.

## How it works
**Round 1: Resume Shortlisting**
The company first checks academic scores, internships, projects and certifications.

**Round 2: Interview Round**
Checks Communication Skills, Soft Skills, Technical Skill, Aptitude, Technical Interview and HR Interview.

**Round 3: Final Placement Result**
Final result is decided based on Round 1 + Round 2.

## Tools Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Random Forest Classifier
